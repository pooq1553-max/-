# 텔레그램 증권사 리포트 아침 브리핑

읽고 싶은 리포트 PDF를 **내 텔레그램 봇에게 전달**해 두면, 다음 날 아침에 봇이 **요약 브리핑**을 보내줘요.

- 노트북을 켜둘 필요 없어요. 클라우드에서 돌아가요.
- Claude API 요금이 따로 안 나가요. 요약은 Claude Code 예약 실행이 구독 사용량 안에서 해요.

## 쓰는 법 (매일)

1. 텔레그램에서 리포트 PDF를 길게 누르고 **전달** → **내 봇**을 골라요.
2. 끝이에요. 매일 아침 7시쯤 봇이 브리핑을 보내줘요.

브리핑에 들어가는 내용이에요.
- 오늘의 핵심 3줄
- 목표가 올린 종목 / 내린 종목
- 투자의견 바뀐 종목
- 섹터별 정리
- 여러 증권사가 같이 다룬 종목
- 리스크
- 리포트별 한 줄 요약

## 알아둘 점

- 봇에게 보낸 메시지는 텔레그램이 **24시간만** 보관해요. 그래서 브리핑은 매일 돌아요.
- **PDF는 20MB까지만** 받을 수 있어요. 봇의 한계예요.
- 봇에게 **처음 메시지를 보낸 사람**만 주인으로 등록돼요. 다른 사람이 보낸 건 무시해요.
- 리포트가 아주 많으면 Claude 구독 사용량 한도에 걸릴 수 있어요.

## 처음 한 번만 하는 설정

클라우드 환경 설정 두 가지가 필요해요.

1. **네트워크:** `api.telegram.org` 허용
2. **환경변수:** `TELEGRAM_BOT_TOKEN` = 봇 토큰

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `telegram_report_digest.py` | `fetch`: 봇에 쌓인 PDF 받기<br>`send`: 브리핑 보내고 읽음 처리 |
| `ROUTINE.md` | 아침 예약 세션이 따라 하는 작업 순서 |
| `config.json` | 받는 사람 번호(chat_id). 첫 실행 때 자동으로 생겨요 |
