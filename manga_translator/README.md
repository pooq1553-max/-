# 만화 자동 번역기 (무료)

만화 이미지 폴더나 zip 파일을 넣으면 외국어 대사를 **한국어로 번역해 말풍선에 넣어 줍니다.**
수십 장을 한 번에 넣어도 알아서 순서대로 처리합니다. 유료 API는 쓰지 않습니다.

| 단계 | 사용 도구 (전부 무료) |
|---|---|
| 글자 위치 찾기 | EasyOCR (내 PC에서 실행) |
| 일본어 읽기 | manga-ocr (세로쓰기 지원, 내 PC에서 실행) |
| 번역 | 구글 번역 무료 주소(키 불필요). 실패하면 MyMemory로 대신 번역. 또는 Ollama 로컬 AI |
| 원문 지우기 + 한글 넣기 | OpenCV, 나눔고딕 |

**지원 언어:** 일본어, 영어, 스페인어, 중국어(간체/번체), 프랑스어, 독일어, 포르투갈어, 이탈리아어, 러시아어, 인도네시아어, 베트남어, 태국어. 창의 **원문 언어**에서 고르면 됩니다.

## 사용법 (Windows 프로그램, 설치 필요 없음)

1. 이 저장소의 **Releases** 페이지에서 최신 `MangaTranslator-windows.zip`을 내려받아 압축을 풉니다.
2. `MangaTranslator` 폴더 안의 **`MangaTranslator.exe`를 더블클릭**합니다. 처음 켜면 바탕화면에 **'만화 번역기' 바로가기**가 생기니, 다음부터는 그걸 누르면 됩니다.
   "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명하지 않은 무료 프로그램이라 뜨는 경고입니다.
3. 만화 폴더나 zip, 이미지를 **창에 끌어다 놓고 `▶ 번역 시작`**을 누릅니다. 여러 개를 한꺼번에 넣어도 됩니다.
4. 오른쪽에 번역된 페이지가 실시간으로 보이고, 다 끝나면 **`결과 폴더 열기`**를 누르면 됩니다.

- 결과는 원본 옆 `이름_한국어` 폴더에 저장됩니다. zip을 넣었으면 zip으로도 저장됩니다.
- 첫 실행 때는 AI 모델(약 1GB)을 내려받느라 몇 분 걸립니다. 두 번째부터는 바로 시작합니다.
- 중간에 멈춰도 다시 실행하면 **이미 번역한 페이지는 건너뜁니다.**
- 결과 폴더의 `번역문.txt`에서 원문과 번역문을 나란히 확인할 수 있습니다.

## 파이썬으로 직접 실행하기 (선택)

`설치.bat`을 한 번 실행한 뒤 만화 폴더를 `번역하기.bat` 위로 끌어다 놓거나, `python app.py`로 창을 띄웁니다.
macOS/Linux에서는 `./run.sh 만화폴더`를 씁니다.

## 옵션 (명령줄)

```
python translate_manga.py 만화폴더 --lang en          # 영어 만화
python translate_manga.py 만화폴더 --lang zh          # 중국어 만화
python translate_manga.py 만화폴더 --lang es          # 스페인어 만화
python translate_manga.py 만화폴더 --max-font 32      # 글자를 더 작게
python translate_manga.py 만화폴더 --font 내폰트.ttf  # 원하는 폰트로 식자
python translate_manga.py 만화폴더 --redo             # 전부 다시 번역
```

## 번역 품질을 더 높이고 싶다면 (역시 무료): Ollama

구글 번역은 대사를 한 줄씩 기계적으로 옮기기 때문에 말투가 딱딱할 수 있습니다.
[Ollama](https://ollama.com)를 설치하면 내 PC에서 AI가 앞 페이지 흐름과 말투를 참고해 번역합니다.
완전히 오프라인이고 무료이지만, 그래픽카드(VRAM 8GB 이상 권장)가 있어야 빠릅니다.

```
ollama pull qwen2.5:7b
python translate_manga.py 만화폴더 --engine ollama
```

## 한계

- 말풍선 안의 대사는 잘 처리합니다. 효과음이나 그림 위 손글씨는 놓치거나 어색할 수 있습니다.
- 그래픽카드(NVIDIA)가 있으면 자동으로 사용합니다. 없으면 CPU로 돌리며, 한 장에 몇 초에서 십몇 초 걸립니다.
- 개인 감상용으로만 쓰세요. 번역본을 배포하면 저작권 문제가 될 수 있습니다.
